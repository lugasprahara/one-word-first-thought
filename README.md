Exactly one word, the first that came to mind: **borborygmus** — the rumbling, gurgling sound a stomach makes. The word is the noise itself, spelled out; say it and you hear it. The program in `main.ts` holds the word, checks it fits the gate (one word, 1–24 characters, no whitespace), and writes it to `/output/entry.txt` — that single word is the whole entry, judged two words at a time on which is more interesting: surprising, vivid, and carrying a spark of wit in its sound.

## Run it

```sh
node main.ts
```
